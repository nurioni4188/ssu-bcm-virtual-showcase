학과소개 및 교육목표

자연·사회재난, 감염병, 공급망 위기에 대응하는 실무형 전문가를 양성합니다. 예방·대비·대응·복구 전 과정을 다루며, 기업의 재해경감활동계획과 사업연속성관리체계 수립·운영 역량을 기릅니다.

목표 1

K-BCMS·COOP 기반 체계 구축 역량

재해경감활동체계(K-BCMS)와 기능연속성(COOP)을 바탕으로, 위기 상황에서도 핵심 기능을 유지·복원하는 체계를 설계합니다.

목표 2

정부정책·ESG 경영에 맞는 전문인력

재난안전관리를 공공정책과 ESG 경영 흐름까지 넓혀, 변화하는 제도 환경에 대응할 인재를 기릅니다.

목표 3

현장 실행력을 갖춘 리더십

지식 습득을 넘어 실제 위기상황에서 판단·실행하고 조직을 이끄는 재난관리 전문가를 목표로 합니다.

학위명 확인 필요 — 모집 포스터에는 "재난관리학석사", 공식 모집요강 표에는 일반학과 공통 "경영학 석사"로 표기되어 있습니다. 지원 전 교학팀에 확인하세요.
전문인력인증서 — 행정안전부장관과 숭실대학교 총장 공동 명의의 기업재난관리 전문인력인증서를 취득합니다.

설계 노트

「AI 에이전트」 과제로서, 이 사이트를 AI 에이전트(Claude)와 함께 만든 과정을 기록합니다. 각 단계에 AI가 실행한 일과 사람이 판단·승인한 일을 구분했습니다.

  1. 1. 자료 입력과 목적 설정사람

    모집 포스터 이미지를 제공하고, 사이트 용도를 "과제용 비공식 사이트"로 정했습니다.

  2. 2. 기획과 초안 제작AI 실행

    포스터 내용을 학과소개·특장점·커리큘럼·진로·모집일정·문의로 구조화해 한 페이지 초안을 만들었습니다. 사용 권한을 확인하지 못한 학교 로고와 사진은 넣지 않았습니다.

  3. 3. 공식 정보 대조AI 실행사람 검토

    공식 홈페이지 모집요강과 비교해 차이 3건을 찾았습니다. 학위명(포스터 "재난관리학석사" / 공식 "경영학 석사"), 문의 전화번호, 서류 제출 방식입니다. 확인되지 않은 쪽을 고르지 않고 두 표기를 함께 보여 주거나 공식 표현을 따랐습니다.

  4. 4. 자동 화면 점검AI 실행

    헤드리스 브라우저로 1440·1100·800·640·390·375px 너비를 점검했습니다. 휴대폰에서 메뉴가 사라지는 문제, 제목 줄바꿈 문제, 고지 띠 여백 문제를 찾아 고쳤습니다.

  5. 5. 배포사람 승인·실행

    AI가 배포 플랫폼에 직접 올리려 했으나 연결 권한 부족으로 실패했습니다. 그래서 AI가 GitHub 저장소에 파일을 올리고, 사람이 Vercel에서 저장소를 연결해 배포했습니다. 이후 수정은 저장소에 반영하면 자동으로 재배포됩니다.
